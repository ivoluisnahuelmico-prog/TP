# PC Builder

Comparador de componentes de PC gamer desarrollado como proyecto académico.

## Funcionalidades
- Catálogo de componentes con tarjetas (nombre, categoría, precio de ejemplo y características).
- Búsqueda por nombre.
- Filtros por categoría.
- Selección de hasta dos componentes para compararlos en una tabla.
- Botón para limpiar la comparación.

## Datos
Los componentes y precios mostrados son **ficticios** (ejemplo). No son precios reales.

## Cómo ejecutar
1. Servir la carpeta: `python -m http.server 8000`
2. Abrir en el navegador: `http://localhost:8000`

## Archivos
- `index.html`: estructura de la página.
- `style.css`: estilos.
- `script.js`: datos de ejemplo y lógica.
- `AGENTS.md`: instrucciones del proyecto.
